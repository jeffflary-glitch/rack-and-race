# Rack & Race

A one-page, 30-lap plan from PC builder to data center technician: three 1-hour sessions a week, a 42U rack that fills one brick per tick, a session timer, and the training, job and support links in one place.

**Live site:** https://jeffflary-glitch.github.io/rack-and-race/

- Tick a lap when that week's three sessions are done; milestones are marked with a diamond.
- Progress saves in the browser on the device you use.
- Lap 1 starts Monday, November 2, 2026.

Everything is in `index.html`; there is no build step.
